# 秒下 VideoGrab · 万能视频下载网站

> 粘贴一个链接，把全网视频存到本地，还能让 AI 把它读成一份带时间戳的笔记。B 站、抖音、小红书、快手、微博、YouTube 等 1700+ 站点，一条链接搞定。

基于开源项目 [yt-dlp](https://github.com/yt-dlp/yt-dlp) 搭建的轻量视频下载站：**单进程 FastAPI 后端 + 零构建纯前端**（HTML / CSS / 原生 JS），没有数据库、没有 node_modules、没有 Redis，解压即跑。

下载之外还带一个 **AI 视频总结**：读平台字幕，生成「一句话概览 + 核心知识要点 + 时间戳章节 + 多层思维导图」，边生成边显示，可导出 Markdown / Word / PDF / 导图 SVG。模型走任意 OpenAI 兼容端点（云端或本地 Ollama 均可），密钥只留在服务端。

## 一、项目介绍

### 它解决什么问题

想保存一个视频，通常要经历：找在线解析站 → 弹广告 → 下载下来带水印 → 清晰度还不由你选。
**秒下** 把这一串压缩成三步：粘贴链接 → 选清晰度 → 点下载。

### 功能一览

| 功能 | 说明 |
|---|---|
| **多平台解析** | 底层用 yt-dlp，自带 1700+ 站点解析器；B 站、抖音、小红书、快手、微博、西瓜、YouTube、X、Vimeo 等已做平台标识 |
| **清晰度自选** | 把平台上十几条音视频流归并成「1080P / 720P / 仅音频」这样人话档位，显示真实体积 |
| **默认 H.264** | 默认优先输出 H.264 (MP4)，Windows / 手机 / 电视 / 剪辑软件都能直接播；平台没有 H.264 时自动兜底，不会下载失败 |
| **抖音免 Cookie** | 抖音走免登录移动端通道，直接给 1080P **无水印**，不用登录、不用装插件 |
| **小红书支持** | 支持带 `xsec_token` 的完整笔记链接 + 登录 Cookie；解析失败会直接告诉你该怎么改链接 |
| **仅音频** | 一键提取 m4a，做播客 / 听书 / 背景音 |
| **合集 / 多 P 批量下载** | 粘贴合集或分 P 链接，勾选后一次提交，逐条进度条，可整批打包成 zip |
| **整段分享文案** | 抖音、小红书那种「7.94 复制打开抖音…」一长段话，直接整段粘贴，自动抠出链接 |
| **在线预览** | 下载前后都能在页面里直接播放确认，不用先落盘 |
| **左右双栏工作台** | 解析成功后，视频信息 / 清晰度 / 下载与 AI 总结**同屏并排**，不用再来回切换；合集 / 多 P 仍走单栏全宽清单 |
| **AI 视频总结** | 右栏常驻面板，笔记 / 章节拆解 / 思维导图三个 tab：读平台字幕生成大纲、核心要点、时间戳章节与知识导图，**流式输出**边生成边看；导出 Markdown / Word / PDF / 导图 SVG 全部前端生成 |
| **零点击不扣费** | 右栏先只读探测：已有笔记秒开、生成中自动接回，都没有才显示「生成 AI 总结」按钮；只有点这一下才会调用模型 |
| **不重复计费** | 同一视频（同一登录态、同一风格）1 小时内重复打开直接复用上次结果；关掉页面、去下载再回来会接回进行中的任务，不会重新调用模型 |
| **基础移动端适配** | ≤1024 / ≤768 / ≤480 三档响应式：工作台上下堆叠、放大态全屏、导图与工具条可横滑；窄屏页眉改两行，「开通 VIP / 导入 Cookie」两个按钮完整保留，手机上能走完「解析 → 下载 → 总结 → 导出」 |
| **Cookie 导入** | 页面右上角「导入 Cookie」，支持请求头 / DevTools 表格 / Netscape / JSON，只粘值也能一键生成；实时列出已识别字段、识别 B 站游客态 Cookie，先用真实链接验证再保存，只存本机浏览器 |
| **自动清理** | 临时文件 30 分钟自动删除，不占硬盘 |

### 界面

- 首页：链接解析主流程 + 功能说明 + 使用步骤 + 会员方案 + 常见问题（这几块保持原样）
- 解析结果工作台：单视频左右双栏（左约 39% 视频信息 / 清晰度 / 下载，右约 61% AI 总结）；合集 / 多 P 仍是单栏全宽清单
- AI 总结面板：右栏常驻，笔记 / 章节拆解 / 思维导图三个 tab，带进度、活体字数、导出工具条；工具栏「放大」可把同一份内容切到 960px 阅读，不重新生成
- 卡密兑换页：`VG-XXXX-XXXX-XXXX` 格式卡密兑换（当前为前端演示）
- 响应式：≤1024 双栏堆叠、≤768 全页单列 + 放大态全屏 + 页眉两行（导航横滑、按钮不隐藏）、≤480 紧凑化；两页页眉页脚逐字一致
- Hero：主标题下方常驻一条 Cookie 引导，说明哪些场景需要导入、只存本机，并可直接打开导入面板
- 视觉：极简白底 + 单一蓝色主色 `#1777FF` + 超大圆角胶囊 + 细 ring 边框 + 大留白

## 二、快速开始

### 环境要求

- Python **3.10+**（开发环境为 3.13）
- Windows / macOS / Linux 均可（Windows 已实测）
- 无需 Node.js、无需数据库

### 1. 安装依赖

```bash
cd free-video-downloader

python -m venv .venv

# Windows
.venv\Scripts\python.exe -m pip install -r requirements.txt
# macOS / Linux
# ./venv/bin/pip install -r requirements.txt
```

`requirements.txt` 里已包含 `yt-dlp`。如果你更想把解析器源码放在项目里（方便手动升级某个版本），也可以下载
[yt-dlp 官方源码](https://github.com/yt-dlp/yt-dlp) 解压到项目根目录的 `yt-dlp/` 目录 —— 程序会**优先使用本地目录**，其次才用 pip 装的那份。

### 2. 准备 ffmpeg（高清合并必需）

高清档位是「视频流 + 音频流」分离的，需要用 ffmpeg 合并。程序按以下顺序查找：

1. `tools/ffmpeg/ffmpeg.exe`（项目内置）
2. 系统 `PATH` 里的 `ffmpeg`
3. `imageio-ffmpeg` 自带的二进制

任选一种即可：

```bash
# 方式一：把 ffmpeg 放进项目内置目录（Windows 示例）
#   下载 https://www.gyan.dev/ffmpeg/builds/ 的 essentials 版本
#   把 ffmpeg.exe 放到 tools/ffmpeg/ffmpeg.exe

# 方式二：直接用系统已装的 ffmpeg
ffmpeg -version

# 方式三：交给 pip 包管理
.venv/Scripts/python.exe -m pip install imageio-ffmpeg
```

> 缺 ffmpeg 也能跑，但「高分辨率视频 + 音频」的合并档位会失败；「仅音频」和平台自带的单文件档不受影响。

### 3. 启动

```bash
# Windows
.venv\Scripts\python.exe run.py --port 8000

# macOS / Linux
./.venv/bin/python run.py --port 8000
```

打开 **http://127.0.0.1:8000** 即可使用。端口被占用时会自动往后找一个空闲端口（控制台会打印实际地址）。

常用启动参数：

| 参数 | 说明 |
|---|---|
| `--port 8000` | 端口，默认 8000，也可用环境变量 `PORT` |
| `--host 127.0.0.1` | 监听地址。想让局域网其他设备访问就改 `0.0.0.0` |
| `--reload` | 开发模式，改代码自动重启 |

### 4. 可调环境变量

| 变量 | 默认值 | 说明 |
|---|---|---|
| `FILE_TTL` | `1800` | 下载好的临时文件保留秒数（30 分钟） |
| `TASK_TIMEOUT` | `1200` | 单个任务最长下载秒数 |
| `MAX_CONCURRENT_TASKS` | `3` | 同时下载的任务数 |
| `BATCH_MAX` | `20` | 一次批量下载最多提交多少条 |
| `PARSE_TIMEOUT` | `45` | 单次解析超时秒数 |
| `PLAYLIST_MAX` | `50` | 合集最多列出多少条 |

### 5. 配置 AI 总结（可选）

不配置也能用，下载功能完全不受影响；只是右栏会提示「服务端尚未配置 AI 模型」，「生成 AI 总结」按钮置灰。配置好 `.env` 后**必须重启服务**（单 worker、配置在模块导入时读取）。

```bash
# 1) 复制配置模板
cp .env.example .env          # Windows: copy .env.example .env

# 2) 填三行就够（任意 OpenAI Chat Completions 兼容服务）
AI_BASE_URL=https://api.deepseek.com/v1
AI_API_KEY=sk-xxxxxxxx
AI_MODEL=deepseek-chat
```

> `AI_BASE_URL` 要带版本段（多数供应商是 `/v1`）。填成 `https://api.deepseek.com` 会 404。

只想用本地模型（Ollama / LM Studio）时，把上面三行留空，改填：

```bash
AI_FALLBACK_BASE_URL=http://127.0.0.1:11434/v1
AI_FALLBACK_MODEL=qwen2.5:7b
```

云端 + 本地都填时是「云端优先、失败自动切本地」——这样可以既享受云端质量，又不怕断网或余额不足。

| 变量 | 默认值 | 说明 |
|---|---|---|
| `AI_BASE_URL` | 空 | 主端点，OpenAI 兼容地址，需带 `/v1` 这类版本段 |
| `AI_API_KEY` | 空 | 主端点密钥，只从服务端读，绝不下发浏览器 |
| `AI_MODEL` | 空 | 主端点模型名 |
| `AI_FALLBACK_BASE_URL` | 空 | 本地兜底端点（Ollama / LM Studio） |
| `AI_FALLBACK_MODEL` | 空 | 本地兜底模型名 |
| `AI_TIMEOUT` | `120` | 单次模型调用超时秒数 |
| `AI_MAX_CHARS` | `12000` | 每次喂给模型的最大字幕字符数，长视频会自动分段 |
| `AI_MAX_SEGMENTS` | `12` | 最多分几段；超出会等距抽样（笔记里会注明） |
| `AI_NOTE_TTL` | `3600` | 笔记结果复用时长（秒）。只存内存，重启失效 |
| `SUBTITLE_TTL` | `1800` | 字幕正文缓存时长（秒） |
| `SUBTITLE_CACHE_MAX` | `50` | 字幕缓存最多几条 |

改完 `.env` 需要重启服务才生效。`.env` 已在 `.gitignore` 里，不会被提交。

## 三、使用方法

### 下载单个视频

1. 复制视频的分享链接（B 站、抖音等可以**直接粘整段分享文案**）；
2. 粘贴到首页搜索框，点「解析」；
3. 解析出标题 / 封面 / 时长 / 作者后，在档位列表里选清晰度（默认已选中推荐档）；
4. 点「下载所选清晰度」，等进度条跑完；
5. 点「保存到本地」，浏览器开始下载，文件名为视频标题。

解析结果右侧可以直接点「预览」在线播放，确认是不是要的那一条。

### 批量下载合集 / 多 P

1. 粘贴合集链接（如 `bilibili.com/list/...`）或多 P 视频链接并解析；
2. 页面会列出清单，勾选需要的条目；
3. 点「批量下载」，每条独立进度条；
4. 全部完成后可以点「打包下载 zip」，一次拿到全部文件（按 `01-标题.mp4` 编号命名）。

> 单次批量上限默认 20 条，可用 `BATCH_MAX` 调整。

### 关于 Cookie（只有部分平台需要）

| 平台 | 是否需要 | 说明 |
|---|---|---|
| 抖音 | **不需要** | 走免登录通道，直接 1080P 无水印 |
| B 站 | 可选 | 不登录一般最高 720P；导入 `SESSDATA` 后可拿 1080P / 4K |
| 小红书 | **需要** | 要登录 Cookie（`web_session`）**且**链接必须带 `xsec_token` |
| 其他站点 | 视平台 | 提示「需要 Cookie」时再导入即可 |

首页搜索框上方也放了一条**「怎么导入 / 填入 Cookie」**引导，点一下直接打开导入面板；页眉右上角也有同一入口（手机上是两行页眉，两个按钮都完整显示）。

导入步骤：

1. 浏览器登录目标站点（**B 站要确认右上角是头像，不是「登录」按钮**）；
2. F12 → Network → 刷新 → 随便点一个请求 → 复制 **Request Headers 里的 `Cookie` 整段**；
3. 点「导入 Cookie」→ 粘贴 → 只粘一串值也没关系，用面板里的「只粘值」小工具选平台一键生成 → 建议附一条该平台的视频链接点「验证」；
4. 验证通过后点「保存」，页眉按钮会变成「Cookie 已导入」。

> **B 站「有 SESSDATA 却还是不行」**：B 站给**未登录的游客也会下发 SESSDATA**，所以只复制这一行
> 不等于已登录。登录态还必须带 `DedeUserID` / `DedeUserID__ckMd5` / `bili_jct`，这正是要复制
> **整段请求头**而不是从 Application 表格里挑一行的原因。导入面板会实时列出已识别字段名，缺
> `DedeUserID` 时直接高亮提示；「验证」还会联网问一次 B 站 `x/web-interface/nav` 的 `isLogin`，
> 游客态直接给出 `stage=guest` 的明确结论，不会再用「能解析出视频」冒充验证通过（游客态同样能
> 解析出 360P/480P）。**验收标准：保存后重新解析，清晰度里出现 720P / 1080P**；只有 480P/360P
> 说明仍被当成游客，此时 AI 总结也会因为拿不到字幕而停在「正在核对字幕（第 N/10 次）」。

Cookie 只保存在**你本机浏览器的 localStorage**，除了发给你自己启动的这个服务，不会上传到任何第三方。
验证响应只返回字段名，绝不回显 Cookie 值。
若在某些内嵌预览窗口里浏览器禁用了本机存储，页面会自动降级为「仅本次页面有效」并在导入面板底部显示
「环境自检 · 页面来源 / 本机存储 / 前端版本」；这时刷新需要重新导入，长期建议使用外部浏览器打开
`http://127.0.0.1:8000/`。AI 面板的空状态也会直接写明「有没有读到 Cookie」。

**小红书特别注意**：分享链接里的 `/explore/<id>` 单独拿出来是取不到数据的，必须带上 `?xsec_token=...`。在网页版打开笔记后直接复制地址栏完整网址即可；只粘 id 时页面会给出提示，不会让你对着「解析失败」猜原因。

### AI 视频总结

解析成功后，结果区直接进入**左右双栏工作台**：左边是视频信息 / 清晰度 / 下载，右边是常驻的 AI 总结面板，两者同时可见。

右栏先发一次**只读**探测（`/api/ai/lookup`，不创建任务、不调用模型、不产生费用），据此决定显示什么：

- 服务端已有这条视频的笔记 → **直接秒开**，顶部标注「生成于 X 分钟前」；
- 这条视频正在生成 → **自动接回** SSE 进度，不会重复提交、不会重复扣费；
- 都没有 → 显示「生成 AI 总结」按钮，**点一次**才开始。抖音 / 小红书等无字幕平台不会一解析就报错。

点「生成 AI 总结」后面板从「读取字幕」开始实时显示进度，20 秒~几分钟不等（取决于视频长度和模型速度）：

1. 面板顶部先显示字幕情况：`N 段字幕 · 覆盖到 12:34` —— 覆盖到片尾说明字幕是完整的；
2. 章节大纲出来后就先渲染出来，之后每整理完一段字幕，要点会继续追加到对应章节；
3. 全部完成后解锁导出：**复制**、**Markdown**、**Word (.doc)**、**PDF**（走浏览器打印，选「另存为 PDF」）、**思维导图 SVG**；
4. 三个 tab 随意切：**笔记**（完整 Markdown）、**章节拆解**（按章节列出要点与时间戳，点时间码跳回原片）、**思维导图**（按「核心概念 / 因果机制 / 证据案例 / 误区边界 / 应用延伸」重组，不是照抄章节；带 ◷ 的节点可点回原片）；
5. 长笔记或 4 层导图在窄栏里不好读时点右上角「**放大**」：同一份内容切到 960px（手机上全屏），不重建、不中断生成、不重复扣费，读完点「×」回右栏；
6. 觉得内容不对，点「重新生成」强制重算（会重新调用模型）。

**支持范围**（一期只基于平台字幕，不做语音转写）：

| 平台 | 能否总结 | 说明 |
|---|---|---|
| B 站 | 视字幕而定 | 需要登录 Cookie 才容易拿到字幕；优先取人工中文，其次平台 AI 字幕 |
| TED / YouTube 等 | 有字幕即可 | 免 Cookie，自动字幕也支持（会标注「自动」） |
| 抖音 / 小红书 | **暂不支持** | 这两个平台的内容没有字幕轨，一期不做语音转写 |
| 其它站点 | 有字幕即可 | 具体看平台是否提供字幕 |

**没有字幕怎么办**：面板会直接说明原因 —— B 站多半是没登录（右上角导入含 `SESSDATA` 的 Cookie 后重试即可），或者 UP 主没上传字幕、平台也没生成 AI 字幕。这类视频目前无法总结，不会拿错内容凑一份笔记。

**关于费用与隐私**：

- 每次总结 3~14 次模型调用：大纲 1 次 + 每段字幕追加 1 次 + 可能补 1 次空章 + 导图 1 次（19 分钟的 TED 实测 3 次，长视频按 `AI_MAX_SEGMENTS` 上限最多约 14 次）；
- 同一视频（同一登录态、同一风格）1 小时内重复打开**不再调用模型**，直接用上次结果；
- 字幕正文与笔记只放服务端内存，不落盘、不入库；Cookie 只发给**你自己启动的这个服务**；
- 服务重启后内存缓存清空，需要重新生成。

### 会员 / 卡密（当前为前端演示）

- 首页「会员」区块：免费版 / 会员版 / 团队版对比；
- `/store` 卡密兑换页：格式校验 + 自动补分隔符，演示卡密 `VG-DEMO-8888-2026`，兑换后权益写入本机 localStorage。

真实校验（卡密签名、支付回调、下载权限拦截）在下一阶段接入后端。

## 四、技术栈

### 后端

| 技术 | 版本 | 用途 |
|---|---|---|
| [Python](https://www.python.org/) | 3.13（兼容 3.10+） | 运行时 |
| [FastAPI](https://fastapi.tiangolo.com/) | 0.162 | Web 框架、自动接口文档 |
| [Uvicorn](https://www.uvicorn.org/) | 0.54 | ASGI 服务器 |
| [Pydantic](https://docs.pydantic.dev/) | FastAPI 依赖 | 请求体校验 |
| [yt-dlp](https://github.com/yt-dlp/yt-dlp) | 2026.10.26 | 核心解析 / 下载引擎 |
| [requests](https://requests.readthedocs.io/) | ≥2.32 | 抖音通道、直链下载 |
| [httpx](https://www.python-httpx.org/) | 0.28 | 封面代理、字幕直连、AI 调用（含 SSE 流式） |
| [FFmpeg](https://ffmpeg.org/) | 6.0 | 音视频合并、格式转换 |

> AI 部分**没有引入任何新依赖**：不装 `openai` SDK，直接用已有的 `httpx` 打
> `/chat/completions`；导出 Word / PDF / SVG 全部在前端做。

### 前端

| 技术 | 说明 |
|---|---|
| 原生 HTML5 | 无模板引擎、无构建步骤，直接由 FastAPI 托管静态文件 |
| 原生 CSS | 单一 CSS 文件 + CSS 变量设计令牌，无预处理器 |
| 原生 JavaScript (ES5+) | IIFE 封装，无框架、无打包、无依赖 |
| Fetch API + 轮询 | 解析、下载、进度查询 |
| `fetch` + `ReadableStream` | 读 AI 总结的 SSE 流，逐帧增量渲染；不可用时自动退回轮询 |
| Blob / `@media print` | Markdown、Word(.doc)、导图 SVG、PDF 导出，全部在浏览器里生成 |
| localStorage | Cookie 与会员状态仅存本机；读写统一走 `header-ui.js` 的安全存储层，被禁用时自动降级到内存并在导入面板显示环境自检 |

### 存储与并发

| 项 | 方案 |
|---|---|
| 数据库 | **不用**。下载任务、AI 任务、字幕缓存全在进程内存，成品文件放 `runtime/downloads` |
| 消息队列 | **不用**。下载用 3 线程池、AI 用独立 2 线程池 `ThreadPoolExecutor` |
| 缓存 | **不用**外部缓存。字幕正文 / 笔记结果放带 TTL 的内存字典 |
| 进度推送 | AI 用 SSE（`asyncio.Queue` + `call_soon_threadsafe`），下载用 1 秒轮询 |
| 过期清理 | 后台 asyncio 协程每 2 分钟扫一次，按 TTL 删文件、删任务、删笔记 |

> 设计取向是「轻量、能跑、易读」：单机单进程，`python run.py` 起来就是一个完整站点。

## 七、已知限制

| 项 | 说明 |
|---|---|
| 无数据库 | 任务表在内存，服务重启后历史任务丢失；成品文件 30 分钟后清理 |
| 单机部署 | 默认 3 任务并发；未做多机任务分片、未做用户体系与限流 |
| 网络依赖 | 需要能访问目标平台。开发环境无法直连 `youtube.com`，此类链接会超时并给出中文提示 |
| 抖音 | 免登录通道偶尔需同 Session 重试（已内置重试）；私密 / 仅好友可见内容仍下不了 |
| 小红书 | 必须带 `xsec_token` 的链接 + 登录 Cookie；图文笔记本身没有视频，无法下载 |
| AI 只读字幕 | 一期不做语音转写（ASR），抖音 / 小红书以及平台没字幕的视频**无法总结**，会明确说明原因 |
| AI 质量取决于模型 | 建议用指令遵循好、上下文够长的模型。小模型可能返回不合规 JSON，页面会提示换模型；分段策略与时间码校正已尽量兜底 |
| AI 结果只存内存 | 笔记与字幕缓存在进程内，1 小时（`AI_NOTE_TTL`）后或重启即失效；没有「我的笔记」历史 |
| AI 成本 | 一次总结 3~14 次模型调用（视分段数而定），费用由你的模型供应商计；同一视频 1 小时内复用不重复计费 |
| AI 与多 worker | 笔记索引与任务表都在进程内存，`--workers > 1` 会导致复用失效（本项目本来就要求单 worker） |
| 付费 | 仅前端页面演示，未接真实支付 / 卡密校验 |
| 移动端 | 已做基础响应式（≤1024 / ≤768 / ≤480：工作台堆叠、放大全屏、导图与工具条横滑、页眉两行且按钮全露出）；未做移动专用交互重构（汉堡菜单、底部固定操作条、导图缩放手势等），小屏读长笔记建议点「放大」 |
| 内嵌预览窗口 | 部分内嵌浏览器禁用/分区 localStorage 或缓冲 SSE；已做内存降级与 SSE 看门狗自动切轮询，但禁用存储时 Cookie 刷新即失效，长期请用外部浏览器 |
| 非商用 | 见下方免责声明 |
